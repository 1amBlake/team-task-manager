# Team Task Manager

An offline desktop task management application for creating, organizing, and tracking tasks and progress.

## Overview

Team Task Manager is a Java desktop application designed to help users manage tasks, organize their work, and track progress.

The current version focuses on a local, offline experience for a single user.

## Features

- Local authentication
- Create, view, modify, and delete tasks
- Task status management
- Task priority
- Task categories
- Search and filter tasks
- Deadline tracking
- Dashboard statistics

## Tech Stack

- Java 21
- JavaFX
- SQLite
- Maven
